3. Introduction to Power BI, completed September 27, 2026. [Link to Tableau Story](https://public.tableau.com/views/PowerBITrainingCertifications_17906314922540/PowerBIStory?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)
In my Initial E-Commerce Profitability Analysis, I used XLOOKUP formulas in Excel to bring product categories and subcategories into the order data using the Unique Order ID. Power BI can automatically detect relationships between imported tables, allowing you to analyze related fields together without creating separate lookup columns. For Southwest's recurring profitability reports, I would choose Power BI because maintaining the relationship in one place reduces duplicate data and the risk of inconsistent lookup formulas. I would still verify the matching keys and check unmatched records before trusting the results.
