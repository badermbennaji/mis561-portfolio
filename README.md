3. Introduction to Power BI, completed September 27, 2026. [Link to Tableau Story](https://public.tableau.com/views/PowerBITrainingCertifications_17906314922540/PowerBIStory?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link). In my Initial E-Commerce Profitability Analysis, I used XLOOKUP formulas in Excel to bring product categories and subcategories into the order data using the Unique Order ID. Power BI can automatically detect relationships between imported tables, allowing you to analyze related fields together without creating separate lookup columns. For Southwest's recurring profitability reports, I would choose Power BI because maintaining the relationship in one place reduces duplicate data and the risk of inconsistent lookup formulas. I would still verify the matching keys and check unmatched records before trusting the results

4. Introduction to DAX in Power BI, completed October 6, 2026. [[Link to Tableau Story](https://public.tableau.com/shared/SF5HHFZTD?:display_count=n&:origin=viz_share_link)]. In my Account Profitability and Service Tiers analysis, I calculated net contribution per account by totaling each customer’s profit and subtracting the cost to serve for that customer’s service tier. I would build this as a measure in Power BI because the result should recalculate when the report is filtered by customer, service tier, or other report selections. A measure is more appropriate than a calculated column because net contribution is an account-level result that should respond to filter context rather than remain fixed on each transaction row. Keeping the calculation in the data model would let Marcus compare account profitability dynamically during a meeting without asking for separate calculations for every view.
